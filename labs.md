# Пересдача лабораторной работы № 1

В рамках пересдачи необходимо написать на C консольную утилиту `kvstore` — хранилище строковых ключей и значений. Программа должна обрабатывать команды, выполнять поиск и изменение записей, а на старших уровнях — загружать и сохранять данные в текстовом и бинарном форматах.

Работа состоит из пяти **вложенных уровней: 4/10, 6/10, 8/10, 9/10 и 10/10**. Для выполнения задания достаточно структур, динамических массивов, строк и алгоритмов поиска и сортировки. Деревья и хеш-таблицы не требуются.

В репозитории опубликованы 59 открытых тестов по всем уровням и проверяющий скрипт.

## Технические требования

Для выполнения лабораторной работы необходимо использовать предоставленный шаблон проекта.

Обязательные требования:

- Сохранить структуру проекта и публичный интерфейс `include/avlset.h`.
- Не изменять предоставленный обработчик команд `src/main.c`.
- Самостоятельно реализовать структуру данных и все необходимые алгоритмы.
- Обеспечить сборку программы с помощью предоставленного `Makefile`.
- Корректно освобождать всю динамически выделенную память.

**Для студентов, использующих Windows, необходимо работать в WSL с Ubuntu.** Инструкция по установке и настройке WSL размещена на сайте курса. Работать с исходным кодом можно через VS Code, подключённый к WSL.

Для установки необходимых инструментов внутри Ubuntu:

```bash
sudo apt update
sudo apt install build-essential python3
```

Все команды сборки и тестирования выполняются в терминале Linux, macOS или WSL.

### Сборка и проверка

Обычная сборка:

```bash
make
```

Отладочная сборка:

```bash
make debug
```

Сборка с санитайзерами для обнаружения ошибок работы с памятью и неопределённого поведения:

```bash
make sanitize
```

Очистка результатов сборки:

```bash
make clean
```

В репозитории курса предоставлены тесты для каждого уровня сложности, включая стресс-тесты. Для самостоятельной проверки используйте Python-скрипт.

Например, проверка уровня 8/10:

```bash
python3 run_tests.py --level 8 --stress
```

Проверка уровня 10/10 с санитайзерами:

```bash
python3 run_tests.py --level 10 --sanitize --stress
```

Скрипт выводит результаты отдельных тестов, время выполнения и сведения об обнаруженных ошибках.

Подробнее об использовании тестов написано в файле `TESTS_README.md` в репозитории.

**Прохождение предоставленных тестов не гарантирует правильность программы.** При проверке могут использоваться дополнительные тесты. Соблюдение требований к алгоритмам, асимптотической сложности и организации программы также проверяется на защите.
