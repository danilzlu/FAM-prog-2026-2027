## Сдача

**Дедлайн: 4 ноября, 09:00.**

Для сдачи лабораторной работы:

1. Создайте **отдельный публичный репозиторий на GitHub** для лабораторной работы.
2. Загрузите в него исходный код и остальные файлы, необходимые для сборки и запуска программы.
3. Убедитесь, что актуальная версия работы находится в ветке `main`.
4. Проверьте, что репозиторий можно клонировать без авторизации командой

   ```bash
   git clone https://github.com/USERNAME/REPOSITORY.git
   ```

5. Отправьте **HTTPS-ссылку на сам репозиторий** через Яндекс Форму:

   **[Отправить лабораторную работу →](ССЫЛКА_НА_ЯНДЕКС_ФОРМУ)**

Ссылка должна иметь вид:

```text
https://github.com/USERNAME/REPOSITORY.git
```

Не присылайте ссылки на отдельные файлы, папки, коммиты, ветки или GitHub Pages.

Версия работы, находящаяся в ветке `main` на момент дедлайна, считается сданной версией.

## Защита

После сдачи лабораторной работы необходимо пройти **устную защиту**.

На защите нужно будет объяснить устройство своей программы, принятые решения и отдельные фрагменты кода, а также ответить на вопросы по использованным средствам языка C.

Запись на защиту будет открыта позднее.

## Самостоятельность работы

Лабораторная работа выполняется **индивидуально и самостоятельно**.

Использование генеративных моделей (ChatGPT и аналогичных инструментов) для генерации кода лабораторной работы запрещено.
