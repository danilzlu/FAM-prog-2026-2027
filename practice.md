<details>
<summary><strong>Как программа компилируется в контесте и как читать ошибки AddressSanitizer</strong></summary>

В контесте включены дополнительные проверки:

- запрещены **массивы переменной длины (VLA)**;
- включён **AddressSanitizer (ASan)** для поиска ошибок при работе с памятью.

### Массивы переменной длины (VLA)

Размер обычного локального массива должен быть известен во время компиляции.

Например, так писать **нельзя**:

```c
int n;
scanf("%d", &n);

int a[n];  // VLA
```

Если размер массива становится известен только во время выполнения программы, такой код в контесте не скомпилируется.

### AddressSanitizer

AddressSanitizer помогает находить ошибки при работе с памятью, в частности выход за границы массива.

Если программа завершилась с ошибкой ASan, найдите в сообщении строку вида:

```text
ERROR: AddressSanitizer: ...
```

Например:

```text
ERROR: AddressSanitizer: stack-buffer-overflow
```

После неё указывается тип обнаруженной ошибки. Например:
- `stack-buffer-overflow` — выход за границы локального массива;
- `heap-buffer-overflow` — выход за границы динамически выделенной памяти;
- `use-after-free` — обращение к памяти после `free`;
- `double-free` — повторный вызов `free` для уже освобождённой памяти.

Ниже ASan печатает стек вызовов. Ищите первую строку, в которой указаны имя вашего файла и номер строки, например:

```text
#0 0x... in main /path/to/main.c:17
```

`main.c:17` означает, что некорректное обращение к памяти было **обнаружено на строке 17**.

Это не обязательно строка, на которой возникла причина ошибки. Например, неправильное значение индекса могло быть вычислено раньше.

### Как запустить те же проверки локально

Если вы используете GCC, программу можно скомпилировать так:

```bash
gcc -std=c23 -Wall -Wextra -Werror=vla -g \
    -fsanitize=address \
    program.c -o program
```

Здесь:

- `-Werror=vla` — запрещает VLA;
- `-fsanitize=address` — включает AddressSanitizer;
- `-g` — добавляет отладочную информацию, чтобы ASan мог указывать строки исходного кода;
- `-Wall -Wextra` — включают дополнительные предупреждения компилятора.

После этого запустите программу как обычно:

```bash
./program
```

или передайте тест из файла:

```bash
./program < input.txt
```

Если ASan обнаружил ошибку, сначала исправьте **первую обнаруженную ошибку**, затем заново скомпилируйте и запустите программу.
