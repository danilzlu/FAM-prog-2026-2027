Типичные ошибки

Все примеры взяты из реальных посылок домашнего контеста.

Авторы не указаны.

Типичные ошибки

Контракт функции

Задача просит реализовать функцию:

int max(int a, int b);

А в посылке:

#include <stdio.h>

int main(void)
{
    int a, b;

    scanf("%d%d", &a, &b);

    if (a > b)
        printf("%d", a);
    else
        printf("%d", b);

    return 0;
}

Вопрос: программа сама по себе корректна.
Почему контест может ответить Compilation Error?

Типичные ошибки

Контракт функции

Проверяющая программа уже содержит свой main:

checker
   │
   ├── main(...)
   │
   └── вызывает max(a, b)

От нас требуется только:

int max(int a, int b)
{
    if (a > b)
        return a;

    return b;
}
Компилируемый файл и правильная реализация требуемого интерфейса — не одно и то же.

Типичные ошибки

Ввод внутри функции

Задача передаёт число через параметр:

void print_time(int seconds);

Но внутри функции снова появляется ввод:

void print_time(int seconds)
{
    scanf("%d", &seconds);

    /* ... */
}

Вопрос: откуда функция должна получить значение seconds?

Типичные ошибки

Ввод внутри функции

При вызове

print_time(3723);

значение уже передано функции:

3723
 │
 ▼
seconds

Повторный scanf не нужен.

Параметры функции — это её входные данные.

Типичные ошибки

Индекс массива

for (int i = 0; i < n; i++) {
    freq[array[i]]++;
}

Вопрос: что здесь является индексом массива freq?

Типичные ошибки

Индекс массива

freq[array[i]]++;

Два разных индекса:

i
│
▼
array[i]
     │
     ▼
freq[array[i]]
Индекс обязан попадать в допустимый диапазон массива.

Например, если

int freq[101];

то значение array[i] должно лежать от 0 до 100.

Типичные ошибки

Таблица частот

Один из вариантов решения:

for (int value = 0; value <= 100; value++) {
    int counter = 0;

    for (int i = 0; i < n; i++) {
        if (array[i] == value)
            counter++;
    }

    printf("%d ", counter);
}

Вопрос: обязательно ли каждый раз снова просматривать весь массив?

Типичные ошибки

Таблица частот

Можно сразу накапливать количество каждого значения:

for (int i = 0; i < n; i++) {
    freq[array[i]]++;
}

Получается соответствие:

значение     0   1   2   3   ...   100
             │   │   │   │          │
частота    freq[0] ...           freq[100]

Массив может хранить не только последовательность данных, но и таблицу соответствия.

Типичные ошибки

Исходное значение уже потеряно

Проверяем, является ли число палиндромом:

while (n != 0) {
    reversed = reversed * 10 + n % 10;
    n /= 10;
}

if (n == reversed)
    return 1;

Вопрос: чему равно n после завершения цикла?

Типичные ошибки

Исходное значение уже потеряно

12321
  ↓
1232
  ↓
123
  ↓
12
  ↓
1
  ↓
0

После цикла исходного 12321 больше нет.

Один из вариантов:

int original = n;

/* изменяем n */

return original == reversed;
Если значение понадобится позже, его нужно сохранить до разрушительного изменения.

Типичные ошибки

Количество и компонента

int hours = seconds / 3600;
int minutes = seconds / 60;
int secs = seconds % 60;

printf("%02d:%02d:%02d", hours, minutes, secs);

Вопрос: что получится для seconds = 3723?

Типичные ошибки

Количество и компонента

3723 секунды

Это:

1 час
2 минуты
3 секунды

Но

seconds / 60

даёт:

62

Это полное количество минут, а не компонент MM.

Сколько всего минут прошло? и что записано в поле минут? — разные вопросы.

Типичные ошибки

Количество и компонента

Для компоненты минут нужен остаток:

int minutes = seconds / 60 % 60;

Для часов в сутках:

int hours = seconds / 3600 % 24;

Для секунд:

int secs = seconds % 60;

Сначала определите математический смысл каждой переменной, а уже потом записывайте формулу.

Типичные ошибки

Формат — часть ответа

printf("%d:%d:%d", hours, minutes, seconds);

Для

1 час 2 минуты 3 секунды

получим:

1:2:3

Вопрос: что делать, если требуется 01:02:03?

Типичные ошибки

Формат — часть ответа

printf("%02d:%02d:%02d",
       hours, minutes, seconds);
01:02:03
В задачах с точным форматом вывода правильное число и правильный ответ — не всегда одно и то же.

Типичные ошибки

Корректно, но слишком долго

Реальная идея решения НОД:

int i = a < b ? a : b;

while (i != 0) {
    if (a % i == 0 && b % i == 0)
        return i;

    i--;
}

Вопрос: алгоритм правильный?
А достаточно ли этого?

Например:

Алгоритм может быть математически корректным, но не укладываться в ограничение времени.

Типичные ошибки

После TLE

Иногда нужно менять не строку кода, а алгоритм.

перебор делителей
        │
        │   слишком долго
        ▼
алгоритм Евклида
int gcd(int a, int b)
{
    while (b != 0) {
        int r = a % b;
        a = b;
        b = r;
    }

    return a;
}

Несколько неудачных локальных исправлений — повод снова посмотреть на способ решения задачи целиком.

Проверка палиндрома в одной из траекторий постепенно потребовала:

      +

      +

      +

      +
дополнительные флаги
      +
switch

Результат:

20 неудачных посылок → OK

Вопрос: какая информация действительно нужна, чтобы проверить палиндром?

Типичные ошибки

Простая задача — сложная программа

Достаточно двух чисел:

int original = n;
int reversed = 0;

while (n != 0) {
    reversed = reversed * 10 + n % 10;
    n /= 10;
}

return original == reversed;
Каждое дополнительное состояние программы — ещё одно состояние, которое придётся правильно поддерживать.

Типичные ошибки

Compilation Error

Контест компилирует не обязательно только ваш файл:

┌───────────────────────────────┐
│ проверяющая программа         │
│                               │
│ int main(void) {              │
│     ...                       │
│     int x = max(a, b);        │
│     ...                       │
│ }                             │
│                               │
│ + ваша реализация max         │
└───────────────────────────────┘
               │
               ▼
              gcc
Нужно соблюдать не только синтаксис C, но и контракт с вызывающим кодом.
