# Подготовка рабочего окружения

Для работы на курсе потребуется установить несколько программ, подготовить компилятор C/C++ и настроить доступ к GitHub.

Инструкция содержит отдельные шаги для **Windows** и **macOS**.

Разбираться в назначении всех используемых команд пока не требуется. Терминал, компиляцию программ, Git и остальные инструменты мы подробно рассмотрим на занятиях.

# Windows

## 1. Установка Visual Studio Code

Visual Studio Code — редактор, который мы будем использовать для написания программ.

1. Откройте официальный сайт Visual Studio Code:

   https://code.visualstudio.com/

2. Скачайте версию для Windows.

3. Запустите установщик и выполните установку.

4. После завершения установки запустите Visual Studio Code.

---

## 2. Установка компилятора

Для компиляции программ на C и C++ мы будем использовать **GCC** из набора **WinLibs**.

### Скачивание WinLibs

1. Откройте сайт:

   https://winlibs.com/

2. Найдите актуальную версию GCC.

3. Выберите сборку:

   * **Win64 (x86_64)**;
   * **UCRT**;
   * **POSIX threads**;
   * **without LLVM/Clang/LLD/LLDB**;
   * архив в формате **ZIP**.

4. Скачайте архив.

### Распаковка

Создайте на диске `C:` директорию:

```text
C:\winlibs
```

Распакуйте скачанный архив в эту директорию.

После распаковки внутри должна находиться директория `mingw64`.

В частности, должен существовать путь:

```text
C:\winlibs\mingw64\bin
```

В этой директории находятся программы `gcc`, `g++` и другие инструменты, которые понадобятся для работы.

---

## 3. Добавление компилятора в PATH

Чтобы запускать компилятор из терминала, необходимо добавить директорию с ним в переменную среды `Path`.

1. Нажмите клавишу **Win**.

2. Начните вводить:

   **Изменение системных переменных среды**

3. Откройте найденное окно.

4. Нажмите **Переменные среды...**

5. В разделе **Переменные среды пользователя** найдите переменную `Path`.

6. Выберите её и нажмите **Изменить**.

7. Нажмите **Создать**.

8. Добавьте новый путь:

```text
C:\winlibs\mingw64\bin
```

9. Нажмите **ОК** во всех открытых окнах.

> **Важно.**
>
> Уже открытые терминалы не увидят изменение `Path`.
> Если терминал был открыт до выполнения этих действий, закройте его и откройте заново.

### Проверка

Откройте **PowerShell** и выполните:

```powershell
gcc --version
```

Если установка выполнена правильно, появится информация об установленной версии GCC.

Затем выполните:

```powershell
g++ --version
```

Эта команда должна аналогично вывести информацию о версии компилятора C++.

Точный номер версии может отличаться.

---

## 4. Установка Git

Git понадобится для работы с репозиториями и хранения истории изменений программ.

1. Откройте:

   https://git-scm.com/

2. Скачайте Git для Windows.

3. Запустите установщик и выполните установку.

На данном этапе можно оставить предлагаемые установщиком параметры по умолчанию.

После завершения установки откройте новый PowerShell и выполните:

```powershell
git --version
```

Если Git установлен правильно, команда выведет его версию.

# macOS

## 1. Установка Visual Studio Code

1. Откройте официальный сайт Visual Studio Code:

   https://code.visualstudio.com/

2. Скачайте версию для macOS.

3. Откройте скачанный архив.

4. Переместите Visual Studio Code в директорию **Applications (Программы)**.

5. Запустите Visual Studio Code.

---

## 2. Установка инструментов разработчика

В macOS компилятор C/C++ можно установить вместе с **Command Line Tools for Xcode**.

Откройте приложение **Terminal (Терминал)** и выполните:

```bash
xcode-select --install
```

Появится окно установки. Подтвердите установку и дождитесь её завершения.

После этого выполните:

```bash
clang --version
```

Если установка выполнена правильно, появится информация об установленной версии Clang.

Clang будет использоваться в качестве компилятора C и C++ на macOS.

---

## 3. Проверка Git

Command Line Tools также содержат Git.

Выполните:

```bash
git --version
```

Если команда выводит информацию о версии Git, дополнительная установка не требуется.

# Проверка рабочего окружения

Теперь проверим, что редактор, терминал и компилятор работают вместе.

## 1. Создайте рабочую директорию

Создайте в удобном месте директорию с названием:

```text
programming
```

Она будет использоваться в этой инструкции для хранения первой программы.

---

## 2. Откройте директорию в Visual Studio Code

Запустите Visual Studio Code.

Выберите:

**File → Open Folder...**

и откройте созданную директорию `programming`.

---

## 3. Создайте программу

Создайте в этой директории файл:

```text
main.c
```

Введите в него следующий код:

```c
#include <stdio.h>

int main(void)
{
    printf("Hello, world!\n");

    return 0;
}
```

Сохраните файл.

---

## 4. Откройте терминал

В Visual Studio Code выберите:

**Terminal → New Terminal**

В нижней части окна появится терминал.

Убедитесь, что терминал открыт в директории `programming`.

---

## Компиляция и запуск в Windows

В терминале выполните:

```powershell
gcc main.c -o main.exe
```

Если команда завершилась без ошибок, в директории появится файл:

```text
main.exe
```

Запустите программу:

```powershell
.\main.exe
```

В терминале должно появиться:

```text
Hello, world!
```

---

## Компиляция и запуск в macOS

В терминале выполните:

```bash
clang main.c -o main
```

Если команда завершилась без ошибок, в директории появится файл `main`.

Запустите программу:

```bash
./main
```

В терминале должно появиться:

```text
Hello, world!
```

# Настройка GitHub и SSH

Для работы с репозиториями курса потребуется аккаунт GitHub.

Чтобы Git мог подключаться к GitHub, настроим подключение по SSH.

---

## 1. Создание аккаунта GitHub

Если у вас ещё нет аккаунта GitHub:

1. Откройте:

   https://github.com/

2. Нажмите **Sign up**.

3. Зарегистрируйте аккаунт.

4. Подтвердите адрес электронной почты, если GitHub попросит это сделать.

Если аккаунт GitHub у вас уже есть, используйте его.

---

## 2. Откройте терминал

### Windows

Откройте **PowerShell**.

### macOS

Откройте приложение **Terminal (Терминал)**.

---

## 3. Создание SSH-ключа

В терминале выполните:

```bash
ssh-keygen -t ed25519
```

Программа предложит выбрать файл, в котором будет сохранён ключ:

```text
Enter file in which to save the key (...)
```

Нажмите **Enter**, чтобы использовать предложенный путь.

После этого программа предложит установить пароль для SSH-ключа:

```text
Enter passphrase (empty for no passphrase):
```

Для простоты можно оставить пароль пустым: нажмите **Enter**, а затем ещё раз **Enter** для подтверждения.

После этого SSH-ключ будет создан.

Будут созданы два файла:

```text
id_ed25519
id_ed25519.pub
```

Первый содержит **закрытый ключ**, второй — **открытый ключ**.

> **Важно.**
>
> Файл `id_ed25519` является закрытым ключом. **Не отправляйте его другим людям и не публикуйте его.**
>
> Файл `id_ed25519.pub`, напротив, содержит открытый ключ. Именно его мы добавим в GitHub.

---

## 4. Получение открытого ключа

### Windows

В PowerShell выполните:

```powershell
Get-Content ~/.ssh/id_ed25519.pub
```

### macOS

В Terminal выполните:

```bash
cat ~/.ssh/id_ed25519.pub
```

В терминале появится строка, начинающаяся примерно так:

```text
ssh-ed25519 AAAA...
```

Скопируйте **всю строку целиком**.

---

## 5. Добавление SSH-ключа в GitHub

Откройте GitHub и войдите в свой аккаунт.

Перейдите:

**Settings → SSH and GPG keys**

Нажмите:

**New SSH key**

В поле **Title** укажите понятное название компьютера, например:

```text
My laptop
```

В поле **Key** вставьте скопированный открытый SSH-ключ.

Для **Key type** оставьте:

```text
Authentication Key
```

Нажмите **Add SSH key**.

GitHub может попросить подтвердить пароль или выполнить дополнительную проверку аккаунта.

---

## 6. Проверка подключения

Вернитесь в терминал и выполните:

```bash
ssh -T git@github.com
```

При первом подключении может появиться сообщение примерно следующего вида:

```text
The authenticity of host 'github.com (...)' can't be established.
...
Are you sure you want to continue connecting (yes/no/[fingerprint])?
```

Введите:

```text
yes
```

и нажмите **Enter**.

При успешном подключении GitHub сообщит, что аутентификация прошла успешно.

Сообщение также может содержать фразу о том, что GitHub не предоставляет shell-доступ. Это нормально.

# Готово

Рабочее окружение подготовлено, если:

* Visual Studio Code установлен и запускается;
* на Windows работает команда `gcc --version`, а на macOS — `clang --version`;
* работает команда `git --version`;
* файл `main.c` успешно компилируется;
* скомпилированная программа запускается и выводит `Hello, world!`;
* у вас есть аккаунт GitHub;
* SSH-ключ создан и добавлен в GitHub;
* команда `ssh -T git@github.com` успешно проходит проверку.

На занятиях мы подробно разберём, что означают использованные здесь команды, как устроен процесс компиляции и как работать с терминалом и Git.

## Настройка Visual Studio Code

После установки компилятора рекомендуется установить несколько расширений для Visual Studio Code. Они добавляют подсветку кода, подсказки и другие удобные инструменты для работы с C и C++.

### Установка расширений

Откройте Visual Studio Code и перейдите в раздел **Extensions** одним из способов:

* нажмите значок **Extensions** на левой панели;
* используйте сочетание клавиш `Ctrl + Shift + X` в Windows или `Cmd + Shift + X` в macOS.

В строке поиска найдите нужное расширение и нажмите **Install**.

### C/C++

Установите расширение **C/C++** от Microsoft.

Оно добавляет поддержку языков C и C++:

* подсветку синтаксиса;
* подсказки при написании кода;
* поиск ошибок;
* навигацию по исходному коду;
* поддержку отладки.

> **Важно.** Расширение C/C++ не является компилятором. Компиляция программы по-прежнему выполняется установленным ранее GCC в Windows или Clang в macOS.

### Дополнительные расширения

В дальнейшем для курса могут понадобиться дополнительные расширения. Информация о них будет добавляться в инструкции по мере необходимости.

Не рекомендуется устанавливать большое количество расширений заранее: многие возможности Visual Studio Code нам пока не понадобятся.

### Запуск программ

На первых занятиях программы будем компилировать и запускать непосредственно из терминала.

Для Windows:

```powershell
gcc main.c -o main.exe
.\main.exe
```

Для macOS:

```bash
clang main.c -o main
./main
```

Не рекомендуется использовать расширения, автоматически компилирующие и запускающие программу по кнопке, например **Code Runner**. На начальном этапе курса важно понимать отдельно этап компиляции и этап запуска программы.

## WSL для Windows

**WSL (Windows Subsystem for Linux)** позволяет запускать Linux-среду непосредственно внутри Windows.

Для прохождения курса WSL **не требуется**. Все задания можно выполнять с помощью стандартного окружения Windows, описанного выше.

WSL можно установить дополнительно, если вы хотите работать с Linux-инструментами или познакомиться с Linux.

### Установка WSL

Откройте **PowerShell от имени администратора** и выполните:

```powershell
wsl --install
```

После завершения установки перезагрузите компьютер.

При первом запуске установленного Linux-дистрибутива система предложит создать имя пользователя и пароль.

> При вводе пароля в Linux символы на экране не отображаются. Это нормально.

### Обновление системы

После первого запуска WSL выполните:

```bash
sudo apt update
```

При необходимости введите пароль, созданный на предыдущем шаге.

### Установка компилятора

Установите набор основных инструментов разработки:

```bash
sudo apt install build-essential
```

Проверьте установку GCC:

```bash
gcc --version
```

### Установка Git

Git можно установить командой:

```bash
sudo apt install git
```

Проверьте установку:

```bash
git --version
```

Обратите внимание: Git внутри WSL и Git в Windows — это две отдельные установки. Если вы собираетесь работать с репозиториями внутри WSL, Git и SSH необходимо настроить непосредственно в WSL.

### Работа с WSL в Visual Studio Code

Для удобной работы с Linux-средой установите в Visual Studio Code расширение **WSL** от Microsoft.

После установки расширения Visual Studio Code сможет открывать проекты непосредственно внутри WSL. При этом встроенный терминал VS Code будет работать в Linux-среде.

### Где хранить проекты

При работе через WSL рекомендуется хранить проекты внутри файловой системы Linux, например:

```bash
~/Programming/
```

Перейти в этот каталог можно командами:

```bash
mkdir -p ~/Programming
cd ~/Programming
```

После этого репозитории можно клонировать непосредственно сюда.

### Важно

Windows и WSL представляют собой разные рабочие окружения.

Если проект открыт и собирается внутри WSL, используйте Linux-компилятор и Linux-команды:

```bash
gcc main.c -o main
./main
```

Если проект собирается непосредственно в Windows, используйте Windows-окружение:

```powershell
gcc main.c -o main.exe
.\main.exe
```

Не смешивайте эти два способа без необходимости.

Если вы не знаете, какой вариант выбрать, используйте основную инструкцию для **Windows без WSL**.
